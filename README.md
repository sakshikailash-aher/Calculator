Calculator

About the Project

This is a simple Calculator web application developed using HTML, CSS, and JavaScript. It performs basic mathematical calculations through an easy-to-use interface.

Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal number support
- Interactive buttons
- Simple and user-friendly design

Technologies Used

- HTML – Structure of the calculator
- CSS – Styling and layout
- JavaScript – Calculator functionality

Project Files

- "index.html" – Structure of the calculator
- "style.css" – Design and styling
- "script.js" – Calculation logic

How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.
4. Start using the calculator.
